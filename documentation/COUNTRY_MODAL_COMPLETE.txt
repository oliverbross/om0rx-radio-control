================================================================================
  API ENDPOINTS
================================================================================

GET /api/country/data
  Returns entire country GeoJSON collection
  Response: GeoJSON FeatureCollection with all countries

GET /api/country/by-name/{name}
  Returns specific country feature
  Parameters: name (URL-encoded country name)
  Response: GeoJSON Feature with geometry and properties
  Error: 404 if country not found

Example:
  curl "http://localhost:8000/api/country/by-name/Greece"

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: View button not working
  → Make sure DXCC data is loaded
  → Check browser console (F12) for errors
  → Try refreshing page

Problem: Country not found
  → Check country name normalization
  → Try different callsign
  → Check console for API response

Problem: Map not rendering
  → Clear browser cache
  → Check canvas support in browser
  → Enable JavaScript in settings

Problem: Marker not visible
  → Check lat/lon values are valid
  → Try different country
  → Check if coordinates are within bounds
