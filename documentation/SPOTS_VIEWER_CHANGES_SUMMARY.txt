================================================================================
  WORKED SPOTS HIGHLIGHTING
================================================================================

How It Works:
1. Page loads
2. JavaScript fetches /logs/qso_log.adif (your QSO log)
3. Parses ADIF format to extract all worked callsigns
4. For each spot in table:
   - Check if callsign is in your log
   - If YES: Apply green highlight ✅
   - If NO: Normal display
5. Updates in real-time as new spots arrive

Colors:
  • Background: Soft green (#10b981, 15% opacity)
  • Text: Bright green (#6ee7b7)
  • Font: Bold
  • Hover: Darker green (#10b981, 25% opacity)

Case Handling:
  • Callsigns are matched case-insensitively
  • "VE3KZE" = "ve3kze" = "Ve3Kze" all match
