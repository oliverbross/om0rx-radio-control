📋 CONSOLE COMMANDS (Copy & Paste)

Connection:
  winKeyerUI.connect()                    ← Connect to device
  winKeyerUI.disconnect()                 ← Disconnect

Feedback Monitoring:
  window.feedbackHandler.getMetricsReport()     ← See all stats
  window.feedbackHandler.getMetrics()           ← Raw data

Testing:
  await window.winKeyerTester.runFullTestSuite()    ← Run all tests
  window.winKeyerTester.getConfigReport()           ← Check config
  window.winKeyerTester.getDiagnosticDump()         ← Debug info

Auto-Reconnect:
  window.winKeyerUI.reconnectManager.getStats()     ← Retry status
  window.winKeyerUI.reconnectManager.startAutoReconnect() ← Manual start

Manual Control:
  winKeyerUI.setWpm(30)                   ← Change speed
  winKeyerUI.sendMacro('M1')              ← Send memory

Simulation (No Hardware):
  window.winKeyerTester.simulateDeviceResponse('pot-change')
  window.winKeyerTester.simulateDeviceResponse('button-press')

📞 TROUBLESHOOTING

Problem: Scripts not loading
Solution: Clear cache (Ctrl+Shift+Delete), hard refresh (Ctrl+Shift+R)

Problem: Device not connecting
Solution: Check USB cable, verify COM port, try different port

Problem: No feedback from device
Solution: Device powered on? Check simulateDeviceResponse() works

Problem: Reconnect not working
Solution: Verify autoReconnectEnabled=true, manually start if needed

For detailed help: See WINKEYER_PHASE3_COMPLETE.md → Troubleshooting
