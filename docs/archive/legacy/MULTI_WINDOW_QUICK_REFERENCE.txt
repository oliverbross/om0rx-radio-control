🔗 HOW THEY SYNC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Spot → Radio:
    Click spot in DX Spots window
    ↓
    Sends frequency to backend
    ↓
    Radio Control window updates frequency instantly
  
  Radio → Logging:
    Change frequency in Radio Control window
    ↓
    Logging & QRZ window shows updated frequency
  
  Logging → Radio:
    Enter callsign in Logging window
    ↓
    QRZ/DXCC data loads
    ↓
    Frequency syncs to Radio window
  
  All → All:
    Any window sends command
    ↓
    Backend broadcasts to all connected windows
    ↓
    All windows stay perfectly synchronized

    • Multiple connections fully supported
    • All sync through shared backend (not cross-window)
    • Disconnecting one window doesn't affect others

    • No rendering of unused sections
