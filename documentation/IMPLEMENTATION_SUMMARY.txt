================================================================================
DATABASE SCHEMA
================================================================================

Location: /data/spots.duckdb
Type: DuckDB (file-based, column-oriented, no server needed)

Table: spots

Core Fields:
  id              BIGINT PRIMARY KEY (auto-increment)
  received_at     TIMESTAMP (when cluster received)
  date_utc        DATE (for daily queries)
  time_utc        TIME (for hourly queries)
  frequency_khz   DOUBLE (from cluster)
  callsign        VARCHAR (DX station)
  spotter         VARCHAR (who spotted it)
  comment         VARCHAR (cleaned)

Derived/Enriched Fields:
  band            VARCHAR (20m, 40m, 80m, etc. - auto-detected)
  mode            VARCHAR (FT8, SSB, CW, etc. - auto-inferred)
  country         VARCHAR (looked up from callsign)
  zone_cq         INTEGER (CQ zone)
  zone_itu        INTEGER (ITU zone)
  continent       VARCHAR (continent code)
  special_tags    VARCHAR (POTA, SOTA, IOTA, etc. - extracted)
  created_at      TIMESTAMP (insert time)

Indexes (10 indexes for performance):
  - idx_spot_received, idx_spot_date, idx_spot_band
  - idx_spot_mode, idx_spot_callsign, idx_spot_spotter
  - idx_spot_country, idx_spot_frequency
  - idx_spot_band_mode, idx_spot_date_band

================================================================================
HOW IT WORKS
================================================================================

1. Automatic Logging:
   cluster_client.py (receives raw spot)
        ↓
   process_cluster_spot() in backend/main.py
        ↓
   log_spot(spot_data) → spots_logger.py
        ↓
   Spot logged to /data/spots.duckdb with automatic:
   - Band detection from frequency
   - Mode inference from comment + frequency
   - Country/zone lookup from callsign
   - Special tag extraction (POTA, SOTA, IOTA, etc.)

2. Data Enrichment:
   Every spot is automatically enhanced with:
   - Calculated band (160m, 80m, 40m, 20m, etc.)
   - Inferred mode (FT8, SSB, CW, etc.)
   - Looked-up country and zones
   - Extracted special event tags

3. Querying:
   Three ways to query:
   a) Python API: logger.get_stats_by_band(), etc.
   b) REST API: curl http://localhost:8000/api/spots/stats/band
   c) Direct SQL: Connect to DuckDB and query directly
