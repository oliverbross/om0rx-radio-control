### **Option B: Programmatic Use**

```python
from services.ft8_service import FT8Service
import asyncio

async def main():
    # Initialize FT8 service
    ft8 = FT8Service(
        mode='FT8',
        mycall='OM0RX',
        mygrid='JN88',
        audio_device='DAX'  # FlexRadio DAX audio
    )
    
    # Set callback for decoded messages
    async def on_message(msg):
        print(f"{msg.timestamp} {msg.freq:.1f} Hz: {msg.message} ({msg.snr:.1f} dB)")
    
    ft8.on_message_decoded = on_message
    
    # Start service
    await ft8.start()
    
    # Let it run
    await asyncio.sleep(60)  # Decode for 60 seconds
    
    # Stop
    await ft8.stop()
    
    # Get all decoded messages
    for msg in ft8.decoded_messages:
        print(f"  {msg.message}")

# Run
asyncio.run(main())
```

2. **Set audio gain** - Aim for -20 to -30 dB input level
3. **Minimize background noise** - Use headphone monitoring
