┌─────────────────────────────────────────────────────────────────────────────────┐
│                          DATA FLOW ON STARTUP                                    │
└─────────────────────────────────────────────────────────────────────────────────┘

   FastAPI Starts
        ↓
   startup_event()
        ↓
   start_wavelog_sync()
        ↓
   WavelogSyncManager.start()
        ↓
   _sync_loop()
        │
        ├──→ full_sync()
        │       ↓
        │   Wavelog API: /api/get_contacts_adif
        │       ↓
        │   Download ADIF (19.2 MB)
        │       ↓
        │   Parse ADIF records
        │       ↓
        │   Insert into /data/wavelog.db
        │       ↓
        │   Update sync_status
        │   (last_full_sync = now, total_qsos = N)
        │       ↓
        │   READY ✅
        │
        └──→ Wait 5 minutes
                ↓
            delta_sync()
                ↓
            Download ADIF (again)
                ↓
            Insert/update records
            (UNIQUE constraint prevents dupes)
                ↓
            Update sync_status
            (last_delta_sync = now)
                ↓
            Wait 5 minutes... REPEAT


┌─────────────────────────────────────────────────────────────────────────────────┐
│                       DATA FLOW ON USER QUERY                                    │
└─────────────────────────────────────────────────────────────────────────────────┘

   User opens app
        ↓
   Searches for callsign "N7BHJ"
        ↓
   API: /api/recent-qsos?callsign=N7BHJ
        ↓
   wavelog_api.get_recent_qsos()
        ↓
   _get_recent_qsos_internal()
        ↓
   db = get_wavelog_db()
        ↓
   qsos = db.get_qsos_by_callsign('N7BHJ', limit=5)
        ↓
   SQL: SELECT * FROM qsos 
        WHERE UPPER(callsign) = 'N7BHJ'
        ORDER BY qso_date DESC, time_on DESC
        LIMIT 5
        ↓
   Parse results into QSO objects
        ↓
   Transform using _transform_wavelog_qso()
        ↓
   Return JSON response
        ↓
   Frontend: Display in "Previous QSOs" table
        
   ⏱️ Total time: < 50ms ✅

   │  ├─→ Parse 20,000 records

   │  └─→ Status: ready ✅

   │
   T=365s (5 min)
   │  DELTA SYNC #1
   │  ├─→ Download ADIF
   │  ├─→ Parse updates
   │  ├─→ Insert/update in SQLite
   │  └─→ Update last_delta_sync timestamp
   │
   T=725s (12 min)
   │  DELTA SYNC #2
   │  └─→ (same as above)
   │
   T=1085s (18 min)
   │  DELTA SYNC #3
   │  └─→ (same as above)
   │
   ... continues every 5 minutes ...
   │

   │      └─→ Sync manager stopped gracefully

┌─────────────────────────────────────────────────────────────────────────────────┐
│                      ERROR HANDLING                                              │
└─────────────────────────────────────────────────────────────────────────────────┘

   Sync Errors:
   ├─ Network timeout → Retry after 1 minute
   ├─ API error → Log error, continue with cached data
   ├─ Parse error → Skip record, continue with others
   └─ DB error → Log error, continue with next sync

   Query Errors:
   ├─ Database locked → Return error, app retries
   ├─ Record not found → Return empty list (normal)
   └─ Parse error → Log, return original data

   All errors logged to: /logs/flex_debug.log
