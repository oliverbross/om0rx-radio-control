📋 WORKFLOW:

  User clicks spot or types callsign
         ↓
  QRZ lookup retrieves gridsquare
         ↓
  2-second countdown begins (user can cancel)
         ↓
  Bearing calculated: grid_from → grid_to
         ↓
  Band checked: is current band in ROTOR_BANDS?
         ↓
  If YES → Rotor moves to calculated bearing
  If NO → AUTO skipped silently

🚀 QUICK START:

  1. Edit config.py:
     - Set ROTOR_HOME_GRID to your grid square (e.g., "JN88TQ")
     - Set ROTOR_BANDS to your antenna configuration
     - Optionally set ROTOR_AUTO_ENABLED = True

  2. Start the web application

  3. In UI, click the AUTO button (next to rotor controls)

  4. Click a spot from cluster or type a callsign

  5. Watch rotor auto-turn to calculated bearing!
