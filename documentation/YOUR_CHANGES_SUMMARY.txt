================================================================================
  ENVIRONMENT VARIABLES
================================================================================

Before starting, you can customize:

TCP_HOST    - SDC computer IP (default: 127.0.0.1)
TCP_PORT    - SDC port (default: 12166)
WS_PORT     - WebSocket port (default: 8091)

Example (Windows):
  $env:WS_PORT=9000
  $env:TCP_HOST="192.168.1.50"
  .\start_webapp.ps1

Example (Linux):
  export WS_PORT=9000
  export TCP_HOST="192.168.1.50"
  ./start_webapp.sh

================================================================================
  TROUBLESHOOTING
================================================================================

"Node.js is not installed"
  → Install from https://nodejs.org/

"npm install failed"
  → npm cache clean --force
  → npm install

"Port 8091 already in use"
  → WS_PORT=9000 .\start_webapp.ps1
  → Update frontend/js/sdc-ticker.js line 19

"SDC bridge won't connect"
  → Check SDC Skimmer is running
  → Verify TCP Broadcast enabled on port 12166
  → Check console output for errors

[See SDC_INTEGRATED_STARTUP.md for full troubleshooting]
