================================================================================
  TECHNICAL SPECIFICATIONS
================================================================================

MODULE: sdc-ticker.js
- Type: JavaScript module (ES6)
- Size: 4.6 KB
- Dependencies: None (vanilla JavaScript)
- Browser API: WebSocket API
- Integration: Vue.js 3 reactive data

DATA PROPERTIES:
- sdcConnected (boolean)
- sdcBuffer (array, max 40 items)
- sdcTickerContent (string)
- sdcWebSocket (WebSocket instance)
- sdcMaxBufferSize (40)
- sdcReconnectDelay (3000ms)
- sdcReconnectAttempts (counter)
- sdcMaxReconnectAttempts (10)

METHODS:
- initSDCTicker() - Initialize WebSocket
- addSDCText(text) - Add to buffer
- updateSDCTicker() - Update display
- scheduleSDCReconnect() - Retry logic
- clearSDCBuffer() - Clear buffer
- cleanupSDCTicker() - Cleanup on unmount

STYLING:
- 98 lines of CSS
- Purple theme with green accents
- Terminal aesthetic
- Pulsing animation
- Custom scrollbars
- Responsive layout

================================================================================
  CONFIGURATION
================================================================================

DEFAULT SETTINGS:
- WebSocket Host: window.location.hostname (auto-detected)
- WebSocket Port: 8091
- Buffer Size: 40 items
- Display Items: 10 (last items shown)
- Separator: "   •   " (bullet points)
- Reconnection Delay: 3 seconds
- Max Reconnect Attempts: 10

REQUIRED FOR SETUP:
1. SDC Skimmer with TCP Broadcast enabled on :12166
2. Node.js v18+ with ws module installed
3. Node.js bridge running on localhost:8091
4. Web app running on http://localhost:8000
