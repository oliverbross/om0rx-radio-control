📊 WHAT YOU GET
────────────────────────────────────────────────────────────────────────────────

DATABASE:
  Location: /data/spots.duckdb (automatically created on first use)
  Type: DuckDB - file-based, column-oriented, no server needed
  
FIELDS LOGGED PER SPOT:
  • received_at (timestamp when cluster sent spot)
  • date_utc, time_utc (for queries)
  • frequency_khz (from cluster)
  • callsign, spotter, comment (from cluster)
  • band (auto-detected)
  • mode (auto-inferred)
  • country, zone_cq, zone_itu, continent (auto-looked up)
  • special_tags (auto-extracted: POTA, SOTA, IOTA, etc.)

AUTOMATIC ENRICHMENT:
  ✓ Band detection: frequency → 20m, 40m, 80m, etc.
  ✓ Mode inference: comment + frequency → FT8, SSB, CW, etc.
  ✓ Country lookup: callsign → country, zones, continent
  ✓ Special tags: comment → POTA, SOTA, IOTA, etc.


🔌 API ENDPOINTS (8 NEW)
────────────────────────────────────────────────────────────────────────────────

STATISTICS:
  GET  /api/spots/count
       → Total spots logged

  GET  /api/spots/stats/band
       → Spots by band (20m, 40m, etc.)

  GET  /api/spots/stats/mode
       → Spots by mode (FT8, SSB, CW, etc.)

  GET  /api/spots/stats/country?limit=20
       → Top countries by spot count

QUERIES:
  GET  /api/spots/recent?limit=100
       → Most recent spots

  GET  /api/spots/callsign/W1AW
       → All spots for a callsign

  GET  /api/spots/special
       → Spots with special tags (POTA, SOTA, IOTA)

EXPORT:
  POST /api/spots/export/csv
       → Export spots to CSV file


🐍 PYTHON API EXAMPLES
────────────────────────────────────────────────────────────────────────────────

from spots_logger import get_spots_logger
from datetime import date

logger = get_spots_logger()

# How many total spots?
print(logger.get_spot_count())

# Today's band distribution
today = date.today().isoformat()
for stat in logger.get_stats_by_band(today):
    print(f"{stat['band']}: {stat['total_spots']} spots")

# Top countries today
for stat in logger.get_stats_by_country(limit=20, date=today):
    print(f"{stat['country']}: {stat['total_spots']} spots")

# Recent spots
for spot in logger.get_recent_spots(limit=10):
    print(f"{spot['callsign']} on {spot['band']} by {spot['spotter']}")

# All spots for a station
ja_spots = logger.get_spots_by_callsign('JA1ABC')
print(f"Found {len(ja_spots)} spots for JA1ABC")

# Special event spots
pota = logger.get_special_event_spots()
print(f"Found {len(pota)} POTA/SOTA/IOTA activations")

🚀 HOW IT WORKS
────────────────────────────────────────────────────────────────────────────────

FLOW:
  DX Cluster (telnet)
       ↓
  cluster_client.py (receives raw spot data)
       ↓
  process_cluster_spot() in backend/main.py
       ↓
  log_spot() in spots_logger.py
       ↓
  Automatic Enrichment:
    frequency_khz → band_from_khz() → band
    comment + frequency → infer_mode() → mode
    callsign → CTY lookup → country, zones, continent
    comment → extract_special() → POTA/SOTA/IOTA tags
       ↓
  /data/spots.duckdb (persistent storage)
