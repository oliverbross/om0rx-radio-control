================================================================================
HOW IT WORKS
================================================================================

Loading Sequence:
1. Browser loads index.html
2. Vue.js 3 library loads (CDN)
3. CSS files load (logging-panel.css, etc.)
4. templates-loader.js executes:
   → Fetches all 11 template files from /templates/ folder
   → Injects templates into #app container
   → Fires 'templates-loaded' event when complete
5. Modular JavaScript loads (js/core.js, js/websocket.js, etc.)
6. app-main.js initializes Vue application

Important: All templates are part of ONE Vue app instance!
          The #app div is still the single Vue root element.
          All Vue data binding works across template boundaries.
