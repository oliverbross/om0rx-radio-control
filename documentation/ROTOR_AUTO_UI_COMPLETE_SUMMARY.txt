HOW TO USE:
================================================================================

SETUP (One-time configuration):
1. Start backend: .\start_webapp.ps1
2. Open http://localhost:8000
3. Settings → Rotor tab
4. Check ☑ Rotator Enabled
5. Scroll to AUTO config section
6. Check ☑ Enable Rotor AUTO
7. Enter your gridsquare (e.g., JN88TQ)
8. Check bands where you have rotor (e.g., 20m-10m)
9. Close settings

USAGE (During operation):
• Click a DX spot → Rotor automatically turns after 2 seconds
• Type a callsign → QRZ lookup triggers auto-rotor
• Click CANCEL button during countdown → Prevent rotor movement
• Change bands in config → Rotor only turns on enabled bands
